# 文件上传服务器 - 临时密钥鉴权使用说明

## 功能说明

所有访问都需要有效的 `key` 参数（支持URL查询参数或表单参数），密钥存储在数据库中，支持自动过期和手动删除。

- 只有 `localhost` 可以创建/删除密钥
- 外部访问必须携带有效的 `key` 参数
- 密钥默认1小时过期，过期自动失效
- 可以提前手动删除禁用密钥

## 管理员操作（仅localhost可执行）

### 1. 创建新密钥

```bash
curl -X POST "http://localhost:5005/api/admin/keys?description=说明文字&expireMinutes=60"
```

参数：
- `description` - 密钥描述（备注用途）
- `expireMinutes` - 过期时间（分钟，默认60即1小时）

返回示例：
```json
{
  "id": 2,
  "key": "44c07e5ff9164766b66fa0ccb3cb1648",
  "description": "user-access",
  "createdAt": "2026-03-30T00:17:49Z",
  "expiresAt": "2026-03-30T01:17:49Z",
  "isDeleted": false
}
```

### 2. 列出所有密钥

```bash
curl http://localhost:5005/api/admin/keys
```

### 3. 删除密钥

```bash
curl -X DELETE http://localhost:5005/api/admin/keys/{key}
```

示例：
```bash
curl -X DELETE http://localhost:5005/api/admin/keys/44c07e5ff9164766b66fa0ccb3cb1648
```

### 4. 清理所有已过期/已删除密钥

```bash
curl -X DELETE http://localhost:5005/api/admin/keys/cleanup
```

## 用户访问方式

### 访问首页

```
http://192.168.1.4:5005?key={密钥}
```

示例：
```
http://192.168.1.4:5005?key=44c07e5ff9164766b66fa0ccb3cb1648
```

### 下载文件

下载链接格式：
```
http://192.168.1.4:5005/api/files/download/{文件id}?key={密钥}
```

### 上传文件

表单需要包含 `key` 隐藏字段：
```html
<form method="post" enctype="multipart/form-data" action="/?key={密钥}">
  <!-- 其他表单字段 -->
  <input type="hidden" name="key" value="{密钥}" />
</form>
```

## 技术实现

- 中间件：`FileUploadServer.Web/Middleware/ApiKeyAuthMiddleware.cs`
- 实体：`FileUploadServer.Core/Entities/ApiKey.cs`
- 管理接口：`FileUploadServer.Web/Controllers/AdminController.cs`
- 数据库表：`ApiKeys`

## 工作流程

1. 需要分享文件时：
   - 我在本地调用创建接口生成临时密钥
   - 上传文件到服务器
   - 将带密钥的完整下载链接发给对方

2. 使用完成后：
   - 对方告诉我使用完成
   - 我调用删除接口删掉密钥
   - 链接立即失效

3. 即使忘记删除，密钥也会在设定时间后自动过期

## 备注

- 时区已经设置为 **北京时间 (Asia/Shanghai)**
- 服务监听 `0.0.0.0:5005`，支持局域网访问
- 防火墙默认开放，不需要额外配置
